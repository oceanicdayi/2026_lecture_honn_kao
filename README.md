## 解讀範圍

前震只能在較大事件發生後回溯定義；「92% 序列有前震」是特定研究樣本的回溯統計，不是即時預測準確率。Seismogenic Index 描述區域／作業尺度的地震產率，低 SI 不等於零風險。停注可能改變注入負載，但不能保證阻止地震或控制其規模。頁內監管措施是建議框架，並非現行法規摘錄。

主要研究：Wang et al. (2026), “Foreshock productivity and rupture nucleation in injection-induced earthquakes in western Canada,” *Science* 393, eaed9893. https://doi.org/10.1126/science.aed9893
